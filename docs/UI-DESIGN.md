# LecTrans - UI 设计规范

> 对应 `ui/design.py` 设计系统的实际实现（tkinter，Apple-inspired Dark Mode）。

## 1. 设计原则

- **低调隐蔽**：深灰界面、无声音输出，课堂使用不显眼
- **信息密度**：双栏对照一屏展示更多内容
- **操作简单**：核心流程只需「开始录音 / 生成总结 / 导出」
- **阅读舒适**：低对比背景层级 + 可调字号

## 2. 色彩系统

实现于 `DesignSystem.COLORS`（`ui/design.py`）：

| 语义 | 键 | 色值 | 用途 |
|------|----|------|------|
| 主背景 | `bg_primary` | `#1C1C1E` | 窗口底色 |
| 次背景 | `bg_secondary` | `#2C2C2E` | 卡片、导航、状态栏 |
| 三级背景 | `bg_tertiary` | `#3A3A3C` | 输入框、下拉框 |
| 悬浮背景 | `bg_elevated` | `#48484A` | hover / 按钮按下 |
| 主文字 | `text_primary` | `#F5F5F7` | 正文 |
| 次文字 | `text_secondary` | `#A1A1A6` | 导航按钮 |
| 弱化文字 | `text_muted` | `#636366` | 说明、状态 |
| 强调色 | `accent` | `#0A84FF` | 主按钮、选中态 |
| 成功 | `success` | `#30D158` | 录音按钮、连接状态 |
| 警告 | `warning` | `#FFD60A` | 提示状态 |
| 错误 | `error` | `#FF453A` | 停止录音、断开状态 |
| 分隔线 | `separator` | `#38383A` | 区域分隔 |

颜色语义遵循 macOS 深色模式；韩语列圆点 `#FF6961`，中文列圆点 `#0A84FF`。

## 3. 字体系统

实现于 `DesignSystem.FONTS`：

| 样式 | 规格 | 用途 |
|------|------|------|
| `display` | Segoe UI 22 bold | 设置页大标题 |
| `title` | Segoe UI 17 bold | 品牌、对话框标题 |
| `heading` | Segoe UI 14 bold | 卡片标题 |
| `body` | Segoe UI 13 | 正文、按钮 |
| `body_bold` | Segoe UI 13 bold | 药丸按钮 |
| `caption` | Segoe UI 11 | 表单标签、导航按钮 |
| `small` | Segoe UI 10 | 辅助说明 |
| `mono` | Consolas 12 | 计时器、时钟 |

正文文本字号支持用户调节（默认 13，保存于 `config.font_size`）。

## 4. 布局

```
┌─────────────────────────────────────────────────────────────┐
│ ● LecTrans 实时课堂翻译          [导出] [历史] [设置]        │ 52px 导航
├─────────────────────────────────────────────────────────────┤
│ [● 开始录音]  00:00  [音频设备 ▾]        [生成总结] [清空]   │ 56px 控制栏
├─────────────────────────────────────────────────────────────┤
│  ┌──────────────────┬──────────────────┐                   │
│  │ ● 한국어          │ ● 中文            │                   │
│  │ [10:23:45]        │ [10:23:45]        │                   │
│  │ 안녕하세요…       │ 你好…             │                   │
│  └──────────────────┴──────────────────┘                   │
├─────────────────────────────────────────────────────────────┤
│ ● ASR: 本地 Whisper · 翻译: MiMo   0 条记录        10:23:50  │ 28px 状态栏
└─────────────────────────────────────────────────────────────┘
```

- 主窗口 1060×720，最小 760×480；双栏等宽自适应
- 设置 / 历史 / 总结均为独立对话框（`Toplevel`），设置与历史带滚动

## 5. 组件工厂

| 方法 | 说明 |
|------|------|
| `make_button(style=primary/secondary/destructive/ghost)` | 标准按钮，含 hover 态 |
| `make_pill_button(color=success/error/accent)` | 录音药丸按钮 |
| `make_card()` | 带 1px 边框的卡片容器 |
| `make_entry()` | 深色输入框（支持密码掩码） |
| `make_label(style=...)` | 语义化标签 |
| `make_separator()` | 水平/垂直分隔线 |
| `apply_theme(root)` | ttk 主题（Combobox/Scrollbar/Progressbar/Treeview）+ Windows 深色标题栏 |

### Windows 深色标题栏

`apply_theme` 通过 `DwmSetWindowAttribute` 设置：

- `DWMWA_USE_IMMERSIVE_DARK_MODE (20)`：启用沉浸式深色
- `DWMWA_CAPTION_COLOR (35)`：标题栏颜色与主背景一致

非 Windows 平台自动降级（异常吞噬），不影响功能。

## 6. 交互设计

| 操作 | 反馈 |
|------|------|
| 开始录音 | 按钮变红「■ 停止录音」，显示计时器，状态栏显示正在录音 |
| 停止录音 | 状态栏显示「正在保存…」，完成后提示「已自动保存到历史记录」 |
| 生成总结 | 模态进度框 + 不确定进度条，完成后弹出总结窗口（复制/保存/关闭） |
| 翻译中 | 识别与翻译解耦，界面始终可操作；待翻译内容按队列顺序显示 |
| 错误 | 弹窗提示（缺少 Key、麦克风失败、识别错误） |

## 7. 跨平台

- ttk 主题与字体在 Windows/macOS/Linux 均可用（字体族自动回退）
- 打开录音 / 定位文件通过 `core/platform_utils.py` 适配三大平台
- 深色标题栏仅 Windows 11/10 生效，其余平台保持系统默认

## 8. 无障碍

- 关键按钮支持键盘 `Tab` 聚焦与 `Space` 触发（tkinter 原生行为）
- 颜色对比度：正文 `#F5F5F7` / `#1C1C1E` ≈ 15:1，满足 WCAG AA/AAA
- 状态变化有文字提示（状态栏 + 弹窗），不仅依赖颜色
