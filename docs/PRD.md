# LecTrans - 产品需求文档 (PRD)

> 版本：v0.2 ｜ 状态：MVP 已实现并完成工程加固

## 1. 产品概述

### 1.1 产品名称

**LecTrans** (Lecture Translator)

### 1.2 产品定位

> "无感、精准、实时的学术助听器" —— 专为在韩国留学的中国学生设计的课堂实时翻译工具。

### 1.3 目标用户

| 用户画像 | 特征 | 核心痛点 |
|----------|------|----------|
| 韩国留学生 | 中文母语，韩语初中级 | 课堂听不懂，笔记记不全 |
| 计算机工学学生 | 有技术背景 | 专业术语翻译不准 |
| 课堂场景 | 不便外放声音 | 普通翻译软件太显眼 |

### 1.4 产品价值

- **实时性**：随讲随翻，跟上课堂节奏
- **隐蔽性**：暗色界面 + 全程静音，不打扰他人
- **智能性**：MiMo 驱动，术语表 + 上下文提升专业翻译质量
- **实用性**：自动存档，一键结构化总结，课后可复习

## 2. 功能需求与实现状态

### 2.1 核心功能

| 编号 | 功能 | 实现状态 | 说明 |
|------|------|----------|------|
| F1 | 实时语音转录 | ✅ 已实现 | 本地 faster-whisper（自适应 VAD）或 Azure Speech |
| F2 | 实时韩中翻译 | ✅ 已实现 | MiMo API，携带最近 N 条双语上下文与术语表 |
| F3 | 一键智能总结 | ✅ 已实现 | 结构化输出：核心概念/知识点/作业考试/待确认问题 |
| F4 | 课堂笔记存档 | ✅ 已实现 | 会话 JSON + 录音（MP3/WAV）+ Markdown 导出 |
| F5 | API 配置管理 | ✅ 已实现 | 设置界面 + 连接测试 + keyring/环境变量 |
| F6 | 界面设置 | ✅ 已实现 | 深色主题、字体/设备/VAD 参数可调 |
| F7 | 历史回看 | ✅ 已实现 | 列表、双语详情、播放录音、定位文件、删除 |
| F8 | **MiMo TTS 语音播报** | 🗺️ 规划中 | 译文实时合成为语音，耳机低音量播放 |
| F9 | 翻译流式输出 | 🗺️ 规划中 | 当前为整句返回 |
| F10 | 导出 PDF / Word | 🗺️ 规划中 | 当前支持 Markdown |

### 2.2 非功能需求

| 指标 | 目标 |
|------|------|
| 转录延迟 | 断句后 < 3s（本地模型视硬件而定） |
| 翻译延迟 | < 2s（网络正常） |
| 内存占用 | 长课堂不随录音时长线性增长（边录边写盘） |
| 稳定性 | 翻译失败自动重试，不阻塞识别 |
| 平台 | Windows 为主，macOS/Linux 可用（文件操作为跨平台实现） |

## 3. 用户故事

```
作为一名在韩国学计算机的留学生，
我希望在课堂上能实时看到教授讲话的中文翻译，
以便跟上课程进度，做好笔记。
```

| ID | 用户故事 | 验收标准 |
|----|----------|----------|
| US-01 | 一键开始录音和翻译 | 点击开始后麦克风与识别就绪 |
| US-02 | 韩语原文与中文并排显示 | 双栏、自动滚动、带时间戳 |
| US-03 | 一键生成课堂总结 | 生成结构化 Markdown 笔记 |
| US-04 | 保存课堂记录 | 停止录音后自动保存；可导出 Markdown |
| US-05 | 暗色静音使用 | 默认深色，无音频输出 |
| US-06 | 配置自己的 API | 设置页可配置并测试连接 |
| US-07 | 保护密钥 | 优先写入系统钥匙串，不落盘明文 |

## 4. 技术方案

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| 界面 | tkinter + ttk | 原生桌面、无浏览器依赖 |
| 音频采集 | PyAudio | 单路采集，边录边写 WAV |
| 本地 ASR | faster-whisper | CTranslate2 加速，自动选择 CUDA/CPU |
| 云端 ASR | Azure Speech SDK | 支持 PushAudioInputStream |
| 翻译/总结 | MiMo (OpenAI 兼容) | 术语表 + 滚动上下文 + 重试 |
| 音频转码 | pydub (ffmpeg) | MP3 不可用时回退 WAV |
| 打包 | PyInstaller | 可移植 spec，Azure 引擎版 exe |

## 5. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 课堂噪音影响识别 | 高 | 自适应能量 VAD + Whisper 内置 vad_filter |
| 长句导致延迟累积 | 中 | 最长句强制切分（默认 20s） |
| API 延迟/抖动 | 中 | 异步 Worker + 重试，UI 不阻塞 |
| 专业术语不准 | 中 | CS 术语表注入 + 双语上下文 |
| ffmpeg 缺失 | 低 | MP3 失败自动保留 WAV 并记录真实路径 |
| 密钥泄露 | 中 | keyring 优先，JSON 回退并限制权限 |
